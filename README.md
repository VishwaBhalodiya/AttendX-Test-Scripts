# AttendX-Test-Scripts

## Project Description
This repository contains basic test scripts for a student attendance application.

## Test Scripts

### 1. login_test.py
Tests valid login details and invalid login details.

### 2. attendance_test.py
Tests attendance marking and detection of an empty student ID.

## Technology Used
- Python
- Git
- GitHub
- Visual Studio Code

## How to Run
Execute the following commands in the terminal:

python login_test.py

python attendance_test.py

## Purpose
The purpose of this project is to manage test scripts using Git and GitHub and maintain a history of changes.

Maintained using Git and GitHub.
